FsVoice Settings Help

Last updated: May 18, 2026

These settings control how FsVoice connects to OpenAI, chooses models, retrieves document context, and processes local source files.

Settings that affect document parsing or indexing usually require reprocessing documents before existing source indexes reflect the change.

Account

SettingWhat it does
OpenAI key Stores the API key used for realtime voice sessions, model calls, and optional keyword generation. Create a key from the OpenAI platform API keys page, then paste it into this field.
Use Case Shows the active workflow definition. Use cases can provide their own prompts, models, and custom settings.
Getting an OpenAI API key: Sign in to the OpenAI platform, open API keys, create a new secret key, and copy it into the OpenAI key field. You may need to choose or create a project first. Store the key somewhere private, because OpenAI only shows the full secret key once.
Use a separate OpenAI API key for each app, device, automation, or experiment when practical. This makes usage easier to monitor and lets you rotate or revoke one key without interrupting unrelated workflows. Keep keys private, monitor usage and billing in the OpenAI platform dashboard, and revoke keys that are no longer needed, exposed, or used on a device you no longer control.

Models

SettingWhat it does
Role model fields Override the model used for each use-case role, such as answering, query rewriting, or keyword generation.

Retrieval

SettingWhat it does
Mode Chooses between the internal document index and the FsColbert retrieval index with fallback behavior.
Lexical Filter Uses keyword and text matching to narrow candidate passages before answer generation.
Log Expansions Adds query expansion details to the app log for troubleshooting retrieval behavior.
Log Chunks Adds selected source chunks to the app log so you can inspect the context sent toward the answer flow.

PDF Parsing

SettingWhat it does
PDF Parser Switches between the newer hybrid parser and the older legacy parser for imported PDF documents.
Layout Analysis Uses local layout detection while parsing PDFs. It is slower, but usually improves reading order and table/figure handling.
Index Keywords Generates extra keywords for indexed passages. This can improve recall and may use OpenAI model calls.

Use Case Settings

SettingWhat it does
Custom fields Settings supplied by the active use case. Their effect depends on the selected workflow.
