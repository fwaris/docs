# Speak2Docs Documentation Site

Published support and store-documentation pages for Speak2Docs.

## Public Pages

- `index.html`: support landing page.
- `fsvoice/settings.html`: settings help.
- `fsvoice/privacy.html`: privacy policy.
- `fsvoice/third-party-notices.html`: third-party notices.

The `fsvoice` path is retained for compatibility with existing app and store URLs, but page copy should present the product as Speak2Docs.

## Store Drafts

- `store-listing.md`: App Store and Play Store listing draft.
- `store-privacy.md`: Apple App Privacy and Google Play Data safety notes.
- `release.md`: release checklist and signing notes.
